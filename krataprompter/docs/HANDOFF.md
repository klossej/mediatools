# Implementation handoff

KråtaPrompter 1.0 uses a Python standard-library server for the web app and Markdown library. Start it with `python3 serve.py` from the tool folder. The LAN bind, data folder, systemd example and test commands are in the [README](../README.md) and [testing guide](TESTING.md).

- `index.html` and `app.mjs` own script editing, file handling, settings and transport. `script.mjs` handles cue parsing and the supported Markdown inline formats. `editor.mjs` converts editable browser content into text runs for the model.
- `presenter.html` and `presenter.mjs` render the companion and relay shortcuts. A fresh private channel name for each operator session keeps independent sessions apart. The full script and state are sent to a newly opened presenter.
- `transport.mjs` advances from a monotonic timestamp. The connected presenter supplies its wrapped line positions scaled to 1080p, and the operator preview matches its aspect ratio. `view.mjs` maps logical character offsets to those positions in each viewport. The presenter keeps a steady speed through wrapping and paragraph changes. Window resizes and font changes reuse the logical position. Both windows project the operator's state locally, so the visible presenter can keep moving if the operator is unfocused. Playback holds its position while both windows are hidden.
- Markdown support is limited to inline bold, italic and underline. Exports use standard Markdown-compatible inline tags for those marks. Text exports preserve cue lines and paragraph breaks.
- `serve.py` serves the app and same-origin library requests. `script_store.py` protects updates by checking the current revision and archiving the exact previous Markdown before atomically replacing it. The archive uses `.revisions/<script name>/<sha256>.md` and remains available on disk for recovery as a separate copy. The last opened or saved filename is stored in `.previous` and loaded at startup. The server only serves public app assets as static files. Manual development uses the isolated `--dev` library, and automated tests launch with temporary data directories.
- The shared transport integrates a smooth velocity ramp over 250 ms on Play and 200 ms on Pause. Layout and visibility changes keep the elapsed phase. The presenter reports changes to its current wrapped line as logical offsets. `editor-follow.mjs` maps those offsets to editor text ranges and adjusts editor scrolling when the current line moves outside the reading area.
- `editor-search.mjs` reuses editor text ranges for literal, case-insensitive searches. It builds an index when the query or manuscript changes and highlights one active result. Search pauses editor follow scrolling. Editor zoom is an operator-session setting applied to the editor text.

## Presentation metadata

`script-file.mjs` reads and writes YAML front matter with `krataprompter: 1`, a `presentation` mapping and a `position` mapping before the manuscript. The presentation keys match `presentation.mjs`, which shares the defaults and validation with the live controls. The reader accepts scalar values in indented mappings with comments and quoted strings. It accepts the example names `lineHeight`, `readingGuide`, `readingGuidePosition`, `mirrorHorizontal` and `mirrorVertical` as aliases for `lineSpacing`, `guide`, `guidePosition`, `presenterMirror` and `presenterMirrorVertical`.

`width`, `horizontalMargin` and `guidePosition` are percentages of the display. `fontSize`, `paragraphSpacing`, `guideSize` and `speed` use the 1080p reference layout. Font families use local fonts with browser fallbacks. `position.cue` is one-based and `position.progress` records the fraction of logical text elapsed between cue boundaries. Cue `0` represents the lead-in before the first cue. Missing or invalid fields use defaults. Opening a file always pauses transport. The position is sampled when saving or downloading Markdown. The optional top-level `title` is the editable script name. `version` stores the last-save stamp in the operator’s local time.

Before broadcast, use the target workstation, monitor and teleprompter glass to check fullscreen placement, mirroring and preferred reading speed. The [operator guide](OPERATOR_GUIDE.md) covers the rehearsal steps.
